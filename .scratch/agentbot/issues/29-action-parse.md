# 29 · F-39 动作流解析

- **Feature**: F-39（P0）
- **里程碑**: M1
- **Status**: resolved
- **前置 ticket**: 无
- **写域（建议）**: internal/agent/

## 目标

模型可能一次输出多个动作，也可能把 JSON 包在代码块里，解析必须容错。

## 交付物

- 剥代码块围栏 → 逐个解码 JSON 对象 → 跳过 `action` 为空的条目 → 非法片段从下一个 `{` 恢复
- **必须启用 `UseNumber()`**
- 返回结果附带 `ParseWarning` 列表

## 验收

- 表驱动 8 组：干净 JSON、代码块包裹、多对象连写、尾随逗号、截断、纯文本、嵌套对象、超大整数
- 大整数（如 `1234567890123456789`）解析后精度不丢
- 动作数量上限 16，超出截断并告警

## 备注（已定决策）

- 以显式扫描 `{` 边界为主、`dec.More()` 只作快路径
- 输入为纯文本时返回空动作列表 + 明确错误，不 panic

## Comments

### 2026-10-02 · 完成记录

实测：`internal/agent/action.go` + 单测。8 种形态表驱动全部通过：干净 JSON、代码块围栏、多对象连写、尾随逗号（告警并从下一个 `{` 恢复）、截断、纯文本（`ErrNoActions`）、嵌套对象、超大整数；**大整数 `1234567890123456789` 精度不丢**（`UseNumber` + `ParamInt64`/`ParamRaw` 断言）；空 `action` 与非对象 `params` 被跳过并各计一条告警；动作上限 5 时截断并报告；空输入返回非 nil 结果 + `ErrNoActions`。解析用显式大括号配对切分，不依赖 `dec.More()` 的顶层非文档语义。
