# 26 · F-33 提示词模板引擎

- **Feature**: F-33（P0）
- **里程碑**: M1
- **Status**: resolved
- **前置 ticket**: 无
- **写域（建议）**: internal/prompt/, prompts/

## 目标

提示词是最常改、最易改坏的资产，需要可版本化、可测试、不重启生效。

## 交付物

- `prompts/**/*.tmpl` + `//go:embed prompts` 内置默认模板
- `text/template` 命名占位，**禁止位置参数**
- 内置函数 `now`/`timezone`/`join`/`quote`/`mdTable`
- 渲染前统一行尾（`\r\n` → `\n`）；渲染结果哈希缓存

## 验收

- CRLF 与 LF 两种检出的模板渲染结果逐字节相同
- 模板写错变量名时启动失败并指出行号
- 单次渲染耗时上限 50ms，超时告警

## 备注（已定决策）

- 模板缺失时回退内置版本，不中断服务
- 表格类输出用 `mdTable`，F-53 的权限表渲染复用它

## Comments

### 2026-10-02 · 完成记录

实测：`internal/prompt/prompt.go` + `templates/system.tmpl` + 单测（9 项）。**CRLF 与 LF 两种检出渲染结果逐字节相同且输出不含 CR**（先归一行尾）；模板引用未知变量时启动期失败并**指出行号**——这里发现 `parse.Pos` 是字节偏移而非行号，已实现偏移→行号换算；语法错误在启动期报出模板名；内置模板启动期校验通过并能渲染（`mdTable` 表头、`timezone` 输出 `2026-10-02T20:00:00+08:00`）；外部同名模板覆盖内置、缺失时回退、完全不存在的模板报错；渲染结果按数据缓存且哈希稳定、数据变化时哈希变化；超过 Timeout 只触发 `OnSlowRender` 告警不失败；`Names()` 同时含内置与外部模板。**修复了一个偶发测试失败**：慢渲染用例原本断言 `time.Since > 1ns`，在 Windows 上时钟粒度可能导致 `Since` 返回 0 而随机失败（在覆盖率运行中复现）；已给 `Options` 增加可注入的 `Measure`，用测试内注入的确定时长替代真实时钟，`-count=20` 重复运行稳定通过。
