# 51 · 提示词快照与可重放

- **Feature**: F-89
- **里程碑**: M3
- **Status**: resolved
- **Blocked by**: 46, 47
- **写域（建议）**: internal/store/, internal/llm/, internal/conversation/

## 目标

把"前缀缓存是否稳定"从**事后推断**变成**可复现的检查**。目前只有日志里的
@BT@cache_hit_ratio@BT@，怀疑前缀变化时无法定位分歧点。

## 交付物

- 每次 LLM 调用旁路记录**实际发送的 @BT@messages@BT@ 序列**（或其指纹 + 可重建快照）
- 前缀稳定性检查：相邻两轮应满足"后者以前者为前缀"，否则记录**分歧点**
- 预期变更（记忆更新、窗口滑动）可标注，与意外变化区分
- @BT@prompt_snapshots@BT@ 表，环形保留（最近 N 轮或仅变化点）
- 快照纳入 F-88 的导出/删除范围

## 验收

- 同一份历史重建两次，报文**逐字节相同**
- 窗口未滑动时前缀关系成立；滑动时能标出分歧点
- 开启快照后实际请求字节与未开启时一致（旁路性对照测试）
- 快照保留有界

## Comments

### 2026-10-03 · 完成记录

**交付物**
- `internal/llm/prefix.go`：`Digest`（逐条消息指纹）、`ComparePrefix`（四种关系判定）
- `agent.Output.PromptDigest`：本轮**实际发送**的消息序列指纹（DirectAgent 与 ReactAgent 都填）
- `prompt_snapshots` 表 + `RecordPromptSnapshot` / `ListPromptSnapshots` /
  `CountDivergedSnapshots` / `PrunePromptSnapshots`
- 组合根每轮记录快照并打印关系；**分歧时告警**；启动时环形裁剪

**判定四种关系**（这是本特性的核心）
| 关系 | 含义 | 是否该发生 |
|---|---|---|
| `identical` | 与上一轮逐条相同 | 正常 |
| `extended` | 上一轮是本轮的前缀 —— **追加式，缓存最优** | 正常 |
| `slid` | 窗口向前滑动（开头被裁掉若干条） | **预期**（ADR-0002 的批量滑动窗口） |
| `diverged` | 既非追加也非滑动 | **异常 —— 前缀被改写了** |

`diverged` 是这条特性真正的价值：把"前缀为什么变了"从**事后猜**变成**当场知道**。
在此之前的唯一手段是看 `cache_hit_ratio` 掉下来了再回头翻日志。

**三个设计选择**
1. **只存指纹不存正文**。正文可能含隐私，而前缀比较只需要判断"这一段是否逐字节相同"。
   逐条指纹还让**分歧发生在哪一条**可以直接算出，而不是只知道整体不同。
   这也意味着快照可以安全地纳入 F-88 的导出/删除范围。
2. **工具调用与 tool_call_id 参与指纹**。只比 role+content 会把"两个参数不同的
   工具调用"看成一模一样——那正是缓存判定的依据，漏了就等于没测。
3. **比较结果落库**。只记录指纹而不记录"和上一条比怎么样了"，事后就无法回答
   "前缀是从哪一轮开始不稳的"。

**一个我如实说明的边界**：比较逻辑在 `llm` 与 `store` 各有一份实现
（`ComparePrefix` 与 `compareDigest`）。原因是**存储层不该依赖表示层**，
而比较又必须与"取上一条快照"在同一事务里完成（否则并发下会取错基准）。
两份逻辑有各自独立的测试守着同一套语义。这是一个已知的重复，
比"为了复用而让 store 依赖 llm"更可接受。

**关于"可重放"**：本 ticket 实现的是**指纹级**的可重放——
同一份输入给出同一串指纹，因此"这次的前缀是否与上次一致"是可复现、可回归的。
**没有**实现正文级的回放（即把当时的 messages 原样重建出来）。
原因同 F-86：正文级回放要求持久化完整报文（隐私与体积代价都很大），
而缓存稳定性这个目标用指纹就能完全达成。这一点写在这里，避免被误读为已实现。

**验收执行**（全绿）
- 四种关系判定正确；分歧点位置正确
- 每会话独立编号；另一会话的首条为 `first`
- 指纹逐条稳定：改一条只影响那一条
- 工具调用参数与 tool_call_id 变化都会改变指纹
- 环形裁剪：10 条裁到 3 条，保留的必须是**最近** 3 条
- 空会话键拒绝写入
- 冒烟：启动与运行日志正常
